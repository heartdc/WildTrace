- 先检查当前工作树、活动进程、构建目录和已有日志；不要因为一次观察超时就重启活跃任务。

- 不下载、安装、联网提交或对外发送材料，除非已有明确授权且动作范围、产物和回滚方式已记录。不要自动提交漏洞或报告。

- 并行委派只用于独立、有限、可审计的子任务。子任务只读时不要让其修改业务文件；合并前检查差异和工作树归属。
