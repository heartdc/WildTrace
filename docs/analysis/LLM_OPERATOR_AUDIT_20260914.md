## 实现

- `llm_adapter` 允许1–300秒整数超时，原调用默认值不变；TimeoutError及其URL包装
  记录为`transport_timeout`，HTTP403仍为`http_status_403`。TLS验证、禁重定向和
  无自动重试保持不变。此设置不是整个命令的严格墙钟时限。
- `llm_review --evidence`独立重建并验证已保存扩展证据，再加入本组片段；请求绑定
  扩展文件摘要，付费调用前和结束后重检。验证需显式提供扩展文件，不跟随嵌入路径。
- `llm_evidence`使用版本化追加提示；保留原L/D引用，增加E片段引用。整片段按优先序
  装入48KiB请求预算，省略ID和原始截断/未穷尽状态显式保留。旧提示和请求摘要不改。
- `review_handoff`保留新引用和原任务状态，模型建议仍不可信，不能自动关闭任务。
- `tools/llm_local.py`提供plan/run/verify/inspect。只有显式run授权才读取本机隐藏
  输入或明确选择的进程环境；配置禁止key字段。输出独占创建，不覆盖旧记录。
