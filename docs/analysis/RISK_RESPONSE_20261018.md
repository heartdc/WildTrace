### 需补：iamf 案的安全危害论证

`ffmpeg_iamf_count_label_dos`（CVE-2026-66037）描述为 "unbounded allocation DoS"。
反馈正确指出备注 4 "普通 DoS 不纳入"。需论证角度：

**上游定性**：上游修复 commit 86708357 主题为 "check count_label against
available bytes (Fixes: unbounded allocation / denial of service)"——上游将其
定为安全缺陷并发 CVE，说明上游认为此 DoS 有安全意义（非普通功能 bug）。

**危害论证**：IAMF 音频解析器在**受信任的系统多媒体服务进程**中运行；恶意
音频文件（网页/即时消息附件场景）触发 `av_calloc(2.68 亿, 8)` = ~2.1GB 瞬时
虚拟内存分配。后果不限于"播放卡顿"：
1. 32 位进程或低内存设备上分配失败 → 解码服务崩溃
2. 大分配挤压物理内存 → OOM killer 可能终止系统关键进程（内存压力型 DoS，
   影响面从单个应用扩展到整机）
3. 上游将其与缓冲区溢出类缺陷同轨修复（Fixes 标签一致），非功能性 bug

**但如实记录**：本案运行级证据为 ASan 分配上限定点拦截（证明分配量不受
约束），非 ASan 堆越界——内存破坏角度不适用。危害定性为"系统服务进程
内不受约束的内存分配，可被远端触发"，不升级为内存破坏主张。
