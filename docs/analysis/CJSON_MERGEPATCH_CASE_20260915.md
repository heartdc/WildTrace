若patch是target拥有的数组/标量子树，target删除时patch随之释放；后续复制
继续读取该对象。这是条件明确的库API生命周期缺陷分析，不是“任意JSON都可
远程攻击”的结论。复现用例不对旧target或借用patch进行二次释放。
