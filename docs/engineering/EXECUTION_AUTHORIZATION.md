# 隔离执行环境授权书（Isolated Execution Authorization）

> 状态：**已签署生效**（双方签署记录见 §8；2026-09-15/16）。本文件是 SECURITY.md 中"不执行目标代码"边界的**范围化正式修正案**：
> 在本文件签署之前，默认边界（不执行目标代码）继续完全有效。签署后，仅在本文件
> 明确列出的范围、环境、边界与留痕要求内，允许编译并运行目标代码以产出验证证据。
> 任一签署方可随时书面撤销本授权；撤销后默认边界立即恢复。

## 1. 授权目的

为静态分析候选产出**运行级验证证据**：在隔离环境中编译授权源码并运行 PoC harness，
采集崩溃/sanitizer 报告，用于候选晋升、独立复现与修复前后对照。执行结果永远只是
证据，不是漏洞确认；确认仍需人工审核（与既有 candidate → review 流程一致）。

## 2. 授权范围（Scope）

**允许执行的目标代码**：仅限本地检出的 OpenHarmony 源码树中，由组件 profile 或
显式文件清单声明的源文件及其依赖。授权根目录以附录 A 的登记表为准，登记表之外的
路径一律视为未授权。

**允许运行的验证代码**：本仓库 `poc/`、`verify/` 或等价目录下、经人工审查入库的
PoC harness 与验证驱动（含 sanitizer 构建参数）。

**禁止执行**：模型生成后未经人工审查入库的任何代码；授权根目录之外的任何代码；
以收集运行时信息以外为目的的任何运行。

## 3. 授权环境（Environment）

- 执行环境为**一次性可恢复的隔离容器**（Docker 或专用 WSL 实例），每次验证任务从
  固定镜像启动，任务结束即销毁；不在任何日常开发主机上直接执行目标代码。
- 镜像版本、编译器版本、sanitizer 配置固定并登记于附录 B；变更需重新登记。
- 资源限额：CPU 时间、内存、单次运行超时（默认 ≤60s）、输出字节上限；超限即杀。
- 运行环境默认无网络；如验证确需网络（如 IPC 回环），须在任务计划中显式声明并
  限定为本机回环接口。

## 4. 授权边界（Boundaries）

| 允许 | 禁止 |
|---|---|
| 编译授权源码（含 ASan/UBSan） | 读取或上传个人凭据、SSH key、token |
| 运行经审查的 PoC harness | 运行期间任何对外网络连接（回环除外，见 §3） |
| 采集崩溃栈、sanitizer 报告、覆盖率 | 修改授权源码树（只读挂载） |
| 记录命令、环境指纹、退出码、哈希 | 将执行结果表述为已确认漏洞或平台结论 |
| 失败与超时的完整记录 | 绕过本授权书或对未登记代码/路径执行 |

## 5. 留痕要求（Evidence）

每次执行必须产出一个可校验的运行记录，至少包含：任务标识、源码 commit/快照摘要、
镜像与编译器指纹、完整命令行、输入文件哈希、退出码、stdout/stderr（有界）、
sanitizer 报告（如有）、产物哈希、parent_run_id（用于独立复现溯源）。记录写入只追加
存储；独立复现任务不得复用生成任务的进程状态或临时文件。

## 6. 与既有安全文件的关系

- 本授权书是 SECURITY.md"不执行目标代码"条款的**唯一**例外通道；
- isolation_contract 的合成 harness 路径不受影响，继续并存；
- 任何 LLM 生成代码必须先经人工审查入库，才可能成为 §2 允许执行的验证代码——
  模型永远不能直接触发执行。

## 7. 撤销与变更

任一签署方在 PR 或 issue 中书面声明即可撤销。范围/环境/边界的任何扩大都需要
重新签署。缩小范围（如移除某个授权根目录）可由任一签署方单方面声明生效。
