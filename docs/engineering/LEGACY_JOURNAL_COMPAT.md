# 旧事务日志兼容说明

## 适用范围

当前日志事件包含 `event`、`task_id`、`created_at` 和事件专用字段。早期日志可能没有 `created_at`，但仍可用于任务状态和事件顺序查看。

## 可验证内容

- `event` 是否属于允许集合。
- `task_id` 是否非空且与查询任务一致。
- 事件顺序是否形成 begin/result/checkpoint/commit 或 abort。
- 归档事件摘要是否与归档内容一致。
- 使用新日志时，`created_at` 是否可用于 `--since` 筛选。

## 不可推断内容

- 旧事件的真实发生时间。
- 缺少的编译器、规则版本、源码提交或环境信息。
- 日志记录是否由可信身份写入。
- 日志是否证明漏洞成立或 OpenHarmony 平台受影响。

## 安全处理

旧日志不会被自动补写时间戳，也不会被静默升级。无时间戳日志可以查看和无时间筛选归档；使用 `--since` 时会拒绝缺少时间戳的事件。需要迁移时，应由人工根据外部可信记录生成新的审计批次，并保留原始日志和迁移说明。

归档筛选会记录 `event_filter` 和 `since`，校验器会检查筛选声明、事件集合和摘要一致。筛选归档不代表完整历史。
